## 3514. 不同 XOR 三元组的数目 II

[题目][lc3514]

[lc3514]: https://leetcode.cn/problems/number-of-unique-xor-triplets-ii/description/?envType=daily-question&envId=2026-07-24

给你一个整数数组 nums 。

 三元组 定义为三个元素的异或值 nums[i] XOR nums[j] XOR nums[k]，其中 i <= j <= k。

返回所有可能三元组 (i, j, k) 中 不同 的 XOR 值的数量。


### 示例 1
**输入：** nums = [1,3]
**输出：** 2

**解释：**
所有可能的 XOR 三元组值为：
- (0, 0, 0) → 1 XOR 1 XOR 1 = 1
- (0, 0, 1) → 1 XOR 1 XOR 3 = 3
- (0, 1, 1) → 1 XOR 3 XOR 3 = 1
- (1, 1, 1) → 3 XOR 3 XOR 3 = 3

不同的 XOR 值为 {1, 3}。因此输出为 2。

### 示例 2
**输入：** nums = [6,7,8,9]
**输出：** 4

**解释：**
不同的 XOR 值为 {6, 7, 8, 9}。因此输出为 4。

### 提示
- 1 <= nums.length <= 1500
- 1 <= nums[i] <= 1500

C++代码：
```
class Solution {
public:
    int uniqueXorTriplets(vector<int>& nums) {
        int n = nums.size();
        // 数字二进制有效位数 bit_width(1u * ranges::max(nums))
        int u = 1 << bit_width(1u * ranges::max(nums)); // 能够构造出来的全部整数

        vector<int> set1(u, 0);
        vector<int> set2(u, 0);

        // 先计算两次遍历能够构造出来的数字
        for (auto x: nums) 
            for (auto y: nums)
                set1[x ^ y] ++ ;
    
        // 再与数组构造一次
        for (auto num: nums) {
            for (int j = 0; j < u; j ++ ) {
                if (set1[j] == 0) continue;
                set2[num ^ j] ++ ; 
            }
        }

        int ans = 0;
        for (auto x : set2) {
            if (x > 0) 
                ans ++ ;
        }

        return ans;
    }
};
```

Go代码：
```
func uniqueXorTriplets(nums []int) int {
    maxval := 0;
    for _, x := range nums {
        if (x > maxval) {
            maxval = x
        }
    }
    // 数字二进制有效位数
    L := bits.Len(uint(maxval))
    u := 1 << L  // 能够构造出来的全部整数

    set1 := make([]int, u)
    set2 := make([]int, u)

    // 枚举所有的x ^ y
    for _, x := range nums {
        for _, y := range nums {
            set1[x ^ y] ++ 
        }
    }

    // (x ^ y) ^ nums
    for _, x := range nums {
        for i := 0; i < u; i ++ {
            if set1[i] == 0 {
                continue
            }
            set2[x ^ i] ++ 
        } 
    }

    ans := 0
    for _, x := range set2 {
        if (x > 0) {
            ans ++ 
        }
    }

    return ans
}
```
